# Goal

## Project
commons-lang — a Java utility library providing helpers that extend java.lang.

## Description
A zero-dependency Java utility library providing null-safe operations on strings, numbers, arrays, objects, booleans, characters, and enums. Includes fluent builders for equals/hashCode/toString/compareTo, immutable and mutable tuple types (Pair, Triple), mutable wrappers for primitives, generic Range, fractional arithmetic, exception chain traversal, regex helpers, system property detection, class introspection utilities, serialization helpers, a stopwatch timer, reflection utilities for fields and methods, argument validation, and concurrent programming utilities (lazy initializers, thread factories, circuit breakers, timed semaphores, memoization).

## Scope
- ~50 production source files to implement (core functionality across 12+ packages)
- ~50 test files to write
- Reproduce all core source code, tests, and configuration
